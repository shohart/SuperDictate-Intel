# Спецификация: пользовательские режимы рерайта (имя · цвет · хоткей · инструкция)

**Ветка:** `feat/llm-postproc-gec` · **Дата:** 2026-08-24
**Основание:** запрос пользователя от 2026-08-24 — «добавь возможность создавать свои режимы рерайта: имя, горячая клавиша, цвет уведомления».

## 1. Решения

1. **Пользовательский режим = `CustomRewriteStyle`**: id (`c-<UUID>`),
   имя, цвет (hex), инструкция для LLM, хоткей (keycode+модификаторы,
   0 = не назначен). Хранится JSON-массивом в
   `rewrite_custom_styles_v1` (UserDefaults).
2. **Активный стиль** хранится в СУЩЕСТВУЮЩЕМ ключе `rewrite_style_v1`
   как строка-id: встроенные (`polish`/`structured_task`/`official`)
   остаются валидными — миграция не нужна; кастомные пишутся как
   `c-<uuid>`. Читается через `rewriteStyleSelection()` →
   `RewriteStyleSelection` (`.builtin(RewriteStyle)` /
   `.custom(CustomRewriteStyle)`); неизвестный id → фолбэк `.polish`.
3. **Промпт кастомного режима** = общий benchmark-база
   (`LLMRewritePrompt.base`, сохранение фактов) + блок
   `Режим <ИМЯ>:` + инструкция из создания/редактирования. Полный
   системный промпт редактируется существующим механизмом
   переопределений (ключ `rewrite_system_prompt_<id>_v1` — тот же, что
   у встроенных; старые оверрайды встроенных продолжают работать).
4. **Суффикс пользователя**: встроенные — как в бенчмарке
   (`POLISH`/`AGENT_TASK`/`FORMAL`); кастомные — `Режим: <ИМЯ>`
   (верхний регистр имени).
5. **Хоткей режима**: активирует этот режим (и включает рерайт, если
   выключен — та же семантика, что у циклического хоткея). Реализация —
   динамический список хоткеев в HotkeyListener (не фиксированные
   свойства): действие `.activateRewriteStyle(id)`.
6. **Цвет тоста**: у кастомного режима — его собственный цвет (hex →
   NSColor); у «Рерайт · вкл» — цвет текущего режима.
7. **Циклический хоткей (F14)** и попап стиля проходят по списку
   встроенные + кастомные (в порядке добавления).
8. **Удаление активного кастомного режима** → фолбэк на `.polish`.
9. **Валидация имени**: непустое, ≤ 40 символов; дубли имён разрешены
   (id различает), но UI предупреждает не будет — id есть id.

## 2. UI (Настройки → «Коррекция»)

- Попап «Режим реврайта»: встроенные + кастомные (в порядке добавления).
- Блок «Свои режимы»: строка на режим — цветной свотч, имя, хоткей
  (HotkeyRecorder-кнопка), «Изменить», «Удалить»; ниже — «＋ Новый
  режим».
- Создание/редактирование — модальный лист: имя (текст), цвет
  (NSColorWell), инструкция режима (многострочное), хоткей
  (HotkeyRecorder-кнопка). Сохранение — в draft, применение — «Сохранить
  и перезапустить» (как остальные настройки).
- Редактор промптов рерайта: переключатель стилей включает кастомные
  (ключ — id).

## 3. Тексты тостов

- Активация кастомного режима: `Режим · <ИМЯ>` цветом режима; если
  рерайт был выключен — `Рерайт · вкл · <ИМЯ>`.

## 4. Тесты

- Хранилище: roundtrip списка кастомных стилей; разрешение selection
  (встроенный/кастомный/неизвестный→polish); удаление активного → фолбэк.
- Промпты: дефолтный системный промпт кастомного = base + блок с
  инструкцией; суффикс `Режим: <ИМЯ>`; оверрайд применяется.
- Хоткеи: действие `.activateRewriteStyle(id)` диспетчеризуется.
